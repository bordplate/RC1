## Learned caveat (object-level checking)

- An object's raw `.text` is NOT byte-identical to the original file segment
  when its INCLUDE_ASM blobs contain linker relocations: menu.o has a
  `.rel.text` section (351 entries) whose `jal`/GOT fixups are patched at
  link time, so e.g. `func_00206978` differs in the raw object (placeholder
  `jalr $ra` words) but matches after linking. Per-function object-byte
  comparison is only valid when the function's range contains no relocations;
  otherwise rely on the full-ELF `cmp`.
