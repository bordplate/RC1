# func_00207690 (vram 0x00207690, file 0x108610, 64 bytes) - MATCHED

## Semantics

This callback has the effective prototype `(int, float, float, float)`. The
first argument is compared against signed `190` (`0x00BE` is positive, not
`-66`), and the third float argument is in `$f14`:

```cpp
if (x >= 190)
    return D_0013D3D8 != 0;
return 58.5f <= y;
```

## Matching Form

EGC emits a 15-instruction candidate for the natural floating-point C form,
omitting the original EE COP1 latency NOP between `mtc1` and `c.le.s`. The
matching form keeps the threshold in a named local and uses it as an FPU input
to the inline asm NOP:

```cpp
float threshold = 58.5f;
asm volatile("nop" : : "f"(threshold));
return threshold <= y;
```

The input constraint forces `lui`/`mtc1` before the asm. The asm supplies the
real hazard NOP; this is source-level inline asm, not a post-build byte patch.
An unbound `asm("nop")` is emitted before the constant materialization and
does not match.
