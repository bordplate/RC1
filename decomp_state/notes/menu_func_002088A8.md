# menu_restoreSelection (vram 0x002088A8, 36 bytes) - MATCHED

## Semantics

The callback writes `3` to `0x15EEB0`, copies `D_0013D290 + 0xBC` to
`D_0013D290 + 0x1C`, and clears `D_0013D290 + 0xF4`.

## Matching Form

`decomp_state/probes/menu_callback.cpp` matches all 36 bytes with
`-fno-schedule-insns2` when the selected value is assigned through the fixed
`$a0` temporary:

```cpp
MenuData* menu = &D_0013D290;
*(int*)0x15EEB0 = 3;
register int selected asm("$4");
selected = menu->saved;
menu->selected = selected;
menu->pending = 0;
```

The isolated probe must be run with:

```sh
python tools/decomp_probe.py decomp_state/probes/menu_callback.cpp \
  decomp_state/probes/reference/menu_callback.s menu_restoreSelection \
  --flags=-fno-schedule-insns2 --out /tmp/opencode/menu-callback
```

The pre-RA-disabled negative control differs at seven instruction positions:

```sh
python tools/decomp_probe.py decomp_state/probes/menu_callback.cpp \
  decomp_state/probes/reference/menu_callback.s menu_restoreSelection \
  --flags=-fno-schedule-insns --out /tmp/opencode/menu-callback-negative
```

## Translation-Unit Isolation

The original single `game/menu` Splat segment was split at exact function
boundaries into three consecutive C++ segments:

- `menu.cpp`: file `0x1078F8..0x109797`, `-fno-schedule-insns`
- `menu_callbacks.cpp`: file `0x109798..0x10984F`, `-fno-schedule-insns2`
- `menu_post.cpp`: file `0x109850..0x109FAF`, `-fno-schedule-insns`

Splat writes those objects consecutively in the linker script, so no padding
or address changes are introduced. This is preferable to changing a large TU's
flags and then adding register hacks to unrelated matched functions. The shared
`MenuData_0013D290` layout is in `code/include/menu.h`, which is covered by the
Makefile's top-level header dependencies.

`config/symbols.txt` renames the original `func_002088A8` to
`menu_restoreSelection`; the callback table relocation is regenerated by
`make split`.
