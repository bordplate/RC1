# UpdateFog__Fi (0x1F2588, 82 words)

Matched 2026-09-27. 82/82 words, clean `make split && make` + full boot ELF
parity. Selects the fog source (underwater vs on-land) based on
`currentCamera.camUnderWater` (Camera field at 0x394, absolute 0x1872D4),
copies the four RGB bytes + four float distances/intensities into the `ViewCtx`
(struct `viewCtx`, 0x18CD00), writes the particle clip distance, then calls
`UpdateViewContext()` and zeroes `levelFogMode` (0x15F498).

## Address map (verified against the boot ELF + the Deadlocked descendant)

The Deadlocked `reference/dl/game_dl/draw.cpp` `UpdateFog` (line 1192) is the
same routine; its debug symbols give the authoritative names, which differ from
the prior session's "occlFog" naming (that was a misnomer — this is *level*
fog vs *water* fog, not occlusion fog).

- Underwater branch (flag != 0, fallthrough): RGB bytes R/G/B from
  `waterFogR/G/B` (0x1610C4/C5/C6); floats near/farIntensity/nearIntensity/
  farDist from `waterFogNearDist/FarIntensity/NearIntensity/FarDist`
  (0x1610C8/CC/D0/D4); clip dist `lui a2,0x4` = **0x40000** (a pure high-16,
  NOT 0x4000 — the first candidate stored 0x4000 and diffed by exactly the
  `lui a2,0x4` word at 0x1F25BC).
- On-land branch (flag == 0): RGB from `levelFogR/G/B` (0x15F484/85/86);
  floats from `levelFog*` (0x15F488/8C/90/94); clip dist `lui v1,0x1f;
  ori v1,v1,0x4000` = **0x1F4000**.
- The clip-distance store target is 0x1600BC (DL `PartClipDist`).
- ViewCtx fields written: fogR/G/B (int, word-stored 0x230/34/38),
  fogNearDist/fogFarIntensity (0x218/1C), fogNearIntensity/fogFarDist
  (0x228/2C). The four floats are interleaved Near/Far/Near/Far by address,
  matching the DL `VC.fogNearDist/FarIntensity/NearIntensity/FarDist` order.

## Codegen levers (all required)

1. **COP1 register pins.** EGC 2.95.2's default COP1 allocation in this
   two-branch context does not reproduce the original's float homes. Pin them:
   underwater near/farIntensity/nearIntensity/farDist -> `$f1,$f2,$f3,$f0`;
   on-land -> `$f3,$f1,$f2,$f0`. Precedent: camera.cpp:348 (`$f21`), :532
   (`$f0`).
2. **Store order = fogR, fogG, fogB, fogNearDist, fogFarIntensity,
   fogNearIntensity, fogFarDist** (bytes, then floats in load order). EGC's
   scheduler then emits the original's `R, P1, G, B, Near, Far, P0` store
   sequence in BOTH branches. The natural "load-order" source order instead
   rotates the last float store to the front in both branches (one-store
   schedule diff); an `asm volatile("")` or memory-clobber barrier "fixes" the
   store position but re-allocates the GPRs and the float load order, so the
   store-order lever is the clean solution.
3. **Mixed-address clip dist.** 0x1600BC is stored GPREL in the underwater
   branch (delay slot of `b` to the epilogue) but self-based absolute in the
   on-land branch. `partClipDist` (plain, self-based) + `partClipDistGp`
   (`config/linker_aliases.ld`, `.extern`-seeded in-function) reproduces both;
   see the in-source comment and the snd_BankLoadByLoc mixed-address note.

## Side fix (pre-existing, surfaced by the offset probe)

`struct ViewCtx` had pad arrays sized in *elements* where the intent was
*bytes*: `pad_180[0x20]` (128 B, should be 32) and `pad_1B0[0x10]` (64 B,
should be 16). At HEAD this placed hvdf at 0x200 and guardX at 0x250 (should
be 0x1A0/0x1C0). It never surfaced because no C function accessed ViewCtx
through the struct before this one (all other users are INCLUDE_ASM raw
addresses). Fixed to `pad_180[0x8]` / `pad_1B0[0x4]`; verified every ViewCtx +
Camera offset with an offsetof probe (needs `#include <stddef.h>` in this EGC).
`Camera.pad_390` was likewise split into `pad_390[4]` + the real
`u32 camUnderWater` at 0x394.

## Naming changes (coherent, parity-preserving)

`occlFogMode`->`partClipDist` (+ `occlFogModeGp`->`partClipDistGp` alias),
`occlFogCtr0/1/2`->`levelFogR/G/B`, `occlFogNear/Far/Param0/Param1`->
`levelFogNearDist/FarIntensity/NearIntensity/FarDist`, `waterFogNear/Far/
Param0/Param1`->`waterFogNearDist/FarIntensity/NearIntensity/FarDist`,
`waterFogCtr0/1/2`->`waterFogR/G/B`, ViewCtx fog fields to the same

the generated INCLUDE_ASM .s files that use them (draw_occl func_001F0CE0,
effects func_001EE4B0, transition func_001E9B10, space func_00230F60) are
regenerated by `make split` with the new names at unchanged addresses.
