- 199 further `branch-epilogue; nop; addiu sp,sp,N` instances in the

- .mdebug symbol SIZES exclude the tail bytes: the tail is gap between
  one symbol's end and the next symbol's start (e.g.
  sceDNAS2InstInit_nohdd 0x3f2200 size 0x14, next symbol 0x3f2220,
  12-byte gap = nop + dead 0x10 unit). So the ORIGINAL COMPILER
  emitted these bytes after the function's RTL; the linker just
  placed them.

Conclusion: a persistent EGC-family artifact (both the RC1-era 2.95.2
and the newer 64-bit Deadlocked compiler emit it), with per-function
sequences that are source- and version-invariant but not derivable
from the decompiled body alone (the original 989snd.c source differs
from the decompiled C in ways that do not affect the live bytes).
