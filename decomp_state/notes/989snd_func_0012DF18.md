## Why no C form can regenerate it

1. The parent `snd_PrepareReturnBuffer` (matched 2026-09-05, see
   decomp_state/notes/snd_PrepareReturnBuffer.md) is frameless: its first byte
   is `sll v0,a1,2` (no prologue) and its last RTL is `jr ra` with the
   `*buf = 0` store in the delay slot. Any C form that gives it a frame
   (locals, VLA, alloca, volatile) inserts a prologue at 0x12DEF8 and breaks
   the 7 matched words, so the parent can never carry the `addiu sp,sp,0x40`.
2. A separate C function in the gap would have to end with `jr ra` (absent —
   0x12DF1C is a nop) or be noreturn with a self-branch (absent — no branch
   at 0x12DF1C). A frameless C function cannot contain
   `addiu sp,sp,0x40` at all.
3. EGC 2.95.2 v2.73a (project flags) never emits a dead `addiu sp,sp,N` after
   an epilogue: sibling probes (t1-t10, /tmp/opencode/tail_exp) produced dead
   stores only, and a 0x40-frame probe emits a single in-delay-slot
   `addiu sp,sp,0x40`, never a stranded one.
