## Escalation (historical)

**last-resort GPT-5.6 Sol used (2026-09-18)** on this exact target
(full dossier: bytes, layout, deadness scans, family + Deadlocked
evidence, t1-t10/p1-p5 probe results, family-head verdict). Verdict:
no acceptable C/C++ form exists. The matched parent is itself the
strongest exact test for the coincidental 0x50-frame case: it compiles
all 272 bytes at 0x12E088-0x12E197 and emits no tail. Merging the
fragment into the parent requires EGC to retain two post-return stack
adjustments (it deletes unreachable RTL and emits only the live
epilogue restoration); a standalone C function must emit a
terminator; folding it into snd_ResolveBankXREFS is impossible (all
six callers enter at 0x12E1A8, whose matched prologue begins there);
scheduler/address-splitting/optimization/assembler flags cannot
synthesize missing RTL. That verdict stands for the C-form question;
it predates the ghost-fragment inline-asm policy applied to the
siblings.

## Resolution (2026-09-24)

Applied the AGENTS.md ghost-fragment policy (2026-09-18 extension):
dead tails are byte-preserved as top-level inline asm at their source
position, not blockers. The INCLUDE_ASM in 989snd_post.c (line 46, the
head of that object's .text, before snd_ResolveBankXREFS) was replaced
with the fragment's exact four words — the two 0x50 deallocations,
the in-fragment nop, and the trailing alignment nop (EGC 8-aligns the
following function, but the explicit nop keeps the layout
independent of that behavior):

```c
asm("addiu $sp,$sp,0x50");
asm("nop");
asm("addiu $sp,$sp,0x50");
asm("nop");
```

No glabel: the fragment is a gap, not a symbol, so the object no longer
defines func_0012E198 (the linker script pins no 989snd function
symbols; section placement is purely cumulative). Splat reclassified
func_0012E198.s into code/_generated/matchings/, the stale
blocked.json entry was removed, and `cmp build/boot_elf.elf
assets/boot_elf.elf` passes. Same pattern as the siblings
func_0012DE60 and func_0012DF18 (989snd_mid.c, 2026-09-23) and
func_0012E078 (989snd_mid_byloc.c, 2026-09-24).
